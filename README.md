# 내 식물 관리 (Plants)

물 줄 때를 놓쳐서 식물이 자꾸 죽는 문제를 막기 위한 식물 관리 앱입니다. 식물마다 물주기 주기를 등록해두면 언제 물을 줘야 하는지 한눈에 보여주고, 물을 준 날을 기록합니다.

## 주요 기능

- 식물 등록 (이름, 종류, 위치, 아이콘, 물주기 주기, 빛 요구량, 메모)
- 다음 급수까지 남은 일수 기준 자동 정렬 (급한 순)
- 물 필요 상태 배지: 지남 / 오늘 / 곧 / 건강
- "물 줬어요" 버튼으로 원터치 기록
- 전체 / 물 필요 / 오늘 급수 요약 통계
- 브라우저 로컬 저장소(localStorage)에 자동 저장, 새로고침해도 유지

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## 기술 스택

React + TypeScript + Vite, 별도 백엔드 없이 localStorage 기반으로 동작합니다.
